The utilities stay the same in both runtime modes

The mode changes who crosses the website boundary, not the purpose or ownership of the data.

Managed modeTokuchu's server automates storefront discovery and cart preparation.
Agent modeThe browser agent explicitly carries the product contract, cart items, and checkout reference between tabs.
